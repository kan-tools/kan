No BLOCK-level finding. No invariant violation: the module is pure, writes nothing, mutates no

A-F1 [MEDIUM, test adequacy] Mapping and state-machine guards that carry the design's source-binding
  and contradiction claims are unpinned by the author suite. R-C1..R-C5, R-C7..R-C9 and R-C11 each pass all
  13 author tests. Concern: a refactor could drop full-frame duplicate equality, direction identity, the
  frame-offset check, the body-span check (cites header bytes) or the final layout check with CI green.
  Follow-up: promote M1-M7, S4, S6, J1, J2 (and the S8/J8 fuzzers at reduced rounds) into CI and
  re-demonstrate R-C1..R-C11 kills.
A-F2 [LOW-MEDIUM, test adequacy] Absolute output accounting is unpinned (R-C10 survives every test).
  Budget tests calibrate limits from an unmutated run, so removing a charge also lowers the
  calibration. This is the same pattern as prior B-N1 for assembly. Follow-up: assert absolute output_bytes
  for a Request and an SSE fixture (e.g. body bytes + pointer/role/text strings + data-line bytes).
A-F3 [LOW-MEDIUM, bound semantics for the Content API] Heap is linear but not what output_bytes
  measures: about 16x per charged JSON byte (Value), about 168 B per item with zero output charged, and
  1 MiB of blank lines gives about 1M items / 176 MB with only `items` bounding it. The design disclaims exact RSS,
  so this is not a defect. Follow-up: Content API budgets must pick items/output with this multiplier, or
  charge Item/Value overhead, and the serialized-response ceiling must be independent.
A-F4 [LOW, labelling] An unknown delta type on a known block gets DeltaType (a contradiction) in addition
  to Unknown (:485-487 compares want=Unknown with Text). citations_delta is a documented Anthropic text-block
  delta, so a legitimate stream is reported as contradictory. Empty-only partial_json ("" fragments) is
  flagged ToolJson and breaks coherence. Whether no-argument tools stream "" under the current protocol
  is UNVERIFIED offline; recheck the primary docs (design asks for this) and add a fixture either way.
A-F5 [LOW, human readability, Content consumer obligation] (a) Request-history items reuse
  Text/ToolUse kinds with provider roles; only Document.format marks them as Context-derived. The UI must
  show that per item. (b) tool_result array content (common in practice) is not rendered and carries no
  issue; J5's nested text is invisible except through raw JSON. (c) The concatenated tool input is checked
  but never exposed; humans must read fragments. (d) Issue codes are inconsistent: unknown root type has
  no Unknown; several Malformed items (:262, :266, :309, :313, :324) carry no issue. The Content plan
  wants structured reason codes, so these will surface as unexplained states.
A-F6 [LOW, raw numeric fidelity] The retained parsed Value is lossy for integers beyond 64 bits
  (f64), and any exponent overflow (1e400) makes the whole body Malformed, so every readable item is lost.
  Raw bytes stay citable via region, so no evidence is lost. Follow-up: document this in the adapter
  version and do not display parsed numbers as raw values; consider a raw-number-preserving parse.
A-F7 [LOW, latent liveness, fail-closed] map_region requires s.offset == next
  (src/evidence_interpretation.rs:707). Assembly accepts zero-length chunks at covered offsets without an
  issue (src/evidence_assembly.rs:293-296), and Recorder::record allows empty chunks
  (src/evidence_capture.rs:186). Such a valid stream interprets but cannot be mapped to source (M8).
  The in-tree gateway does not emit empty chunks (chunks() over empty), so this is latent. Follow-up:
  accept validated zero-length segments at covered offsets, or have assembly report them, and test it.
A-F8 [LOW, SSE visibility] A leading UTF-8 BOM is not stripped (WHATWG strips it), so a BOM-prefixed
  first data line is silently dropped. That surfaces only indirectly as a non-coherent stream. Unknown
  field lines and dataless blocks are issue-free Protocol items that do not affect
  coherent_stop_observed, even after message_stop (S2/S3). This is spec-faithful (undispatched), but an
  evidence browser should flag unknown field names other than id/retry as Unknown.
A-F9 [INFO] Item-level issue locality (R-C6) and empty-region boundary citations (R-C12, M7: both
  neighbours cited) are unpinned. Decide and document the empty-region rule before UI navigation uses it.
