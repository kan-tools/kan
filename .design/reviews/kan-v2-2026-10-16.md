## Disposition and required work

**The stack remains blocked by P2.** Its reviewer reproduced a codec defect: the dependency's generic IPLD decoder converts some ordinary byte strings beginning with CID-parseable bytes into links. The canonical re-encoding check then rejects valid manifests/captures. Reproduced cases include slots, operation tokens and payload hashes beginning `00 01 55 12 00`; the independent Python encoder accepts them. This is rejection of valid evidence, not an observed loss from any live v2 archive. No live archive has been imported.

The next contract fix must preserve CBOR byte-string versus link identity and add the failing vectors plus a negative control that detects reverting the fix. The same review also found weaknesses in the Python oracle's map/link representation, unspecified CID profiles in unsupported records, mutation-test blind spots, missing error-class/inventory vectors and incomplete snapshot/parent-coverage definitions. Those findings remain open; none is erased by the previously passing fixture suite. Corrected commits require a new cold Opus 5.5 review.

P3 approval does not approve completion of parent startup/performance, projection recovery or multi-host criteria. Open follow-ups include the full-archive audit in `open`, recovery when derived rows diverge, recomputation of `first_manifest`, backup sidecar/catalog coverage, interrupted initialization, raw/derived catalog labels and targeted conflict-path tests. The report's backup-sidecar observation used system SQLite, not the bundled Rust path; reproduce that path before treating the observation as established there. The author has not accepted a quiet deferral of the parent performance or recovery requirements.

P5 preflight approval does not cover full discovery/migration acceptance. Open follow-ups include publication-only and explicit-store discovery, typed diagnostics/completeness and absent-medium reporting, public identity-ledger coverage or explicit omission, bare-relative init/backup paths, errors carrying paths, real-writer CAR and unreadable-directory fixtures.
