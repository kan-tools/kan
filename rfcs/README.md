# Requests for Comments

RFCs are reviewed proposals for kan's public protocols, interfaces,
governance, and other cross-cutting commitments. The process and its
relationship to Architecture Decision Records are defined by
[RFC 0000](0000-rfc-and-adr-process.md).

## Index

- [RFC 0000: RFC and ADR process](0000-rfc-and-adr-process.md) — Accepted

The next expected proposal is RFC 0001, the kan URI scheme. Its contents are
intentionally not specified by RFC 0000.
